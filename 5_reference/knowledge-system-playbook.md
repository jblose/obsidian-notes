# Knowledge System Playbook

## 🧭 Summary
This vault is organized around daily capture, project execution, people context, a master task tracker, and durable references.

## 🗂 Category
- note-taking

## 📝 Details
- Start each day from a daily note in `1_daily/`.
- Promote ongoing work into `2_projects/` using the project template.
- Keep collaboration context in `3_people/`.
- Put durable how-to material in `5_reference/` with frontmatter so the dashboard can list it.
- Use `#idea` and `#decision` tags to populate dashboard sections.
